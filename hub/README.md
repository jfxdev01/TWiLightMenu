# TWiLight Hub

Camera, Wi-Fi and internet utilities for TWiLight Menu++, with an interface
inspired by the current Nintendo system menus (big tiles, round shortcut
buttons, button hints, dark and light themes).

It is installed as `/_nds/TWiLightMenu/hub.srldr` and opened from the SELECT
menu of the DSi/3DS/Saturn/HBL themes or from the DS Classic menu.

| App | What it does |
| --- | --- |
| **Camera** | Live preview from the inner/outer camera, colour effects (B&W, sepia, negative, warm, cool), 3 s self-timer, 640x480 photos saved as JPEG in `/DCIM/100TWLHB`. |
| **Album** | Thumbnails of every photo in `/DCIM` (Hub photos and the Nintendo DSi Camera's own photos), viewer with 1:1 detail on the touch screen, delete. |
| **Browser** | Text-mode web browser: HTTP and HTTPS (Mbed TLS, certificates checked against a built-in set of root certificates), address bar with search, bookmarks, history, GET/POST forms, reader mode, image viewer and file downloads (e.g. homebrew `.nds`) to `/downloads`. |
| **Wi-Fi** | Scans networks and connects to open, WEP and — in DSi mode — WPA/WPA2 networks. Passwords typed in the Hub are remembered; the console's own connection settings are also used. |
| **Weather** | Current conditions and a 3 day forecast (wttr.in), °C/°F. |
| **Clock** | Sets the console's real time clock from an NTP server with a configurable time zone. |
| **Box Art** | Scans the ROM folders set in TWiLight Menu++ and downloads the missing covers from GameTDB into `/_nds/TWiLightMenu/boxart`. |
| **System** | Console, storage, battery and network information; Hub settings (sound effects, theme, language, Wi-Fi mode). |

The round buttons on the home screen switch the theme and the language
(Português/English), open the TWiLight Menu++ settings or their
*Installation* page, and go back to the menu.

Settings are stored in `/_nds/TWiLightMenu/hub/hub.ini`. Extra root
certificates can be added by placing a `cacert.pem` in the same folder.

## Building

Unlike the rest of TWiLight Menu++, the Hub is built with
[BlocksDS](https://blocksds.skylyrac.net/): it needs the DSi-mode Wi-Fi driver
(WPA2), the DSi camera driver, Mbed TLS and libcurl, which are part of it.

```sh
# From the repository root
docker run --rm -v "$PWD":/work -w /work/hub skylyrac/blocksds:dev-v1.24.0 make dist
```

or, with BlocksDS installed natively:

```sh
wf-pacman -Sy blocksds-toolchain blocksds-mbedtls blocksds-libcurl toolchain-gcc-arm-none-eabi-zlib
make -C hub dist
```

`make dist` copies the result to `7zfile/_nds/TWiLightMenu/hub.srldr`.

### Previewing the UI on a PC

`tools/sim` builds the Hub for Linux with a fake console that renders the
screens into PNG files, driven by a small script:

```sh
make -C hub/tools/sim
hub/tools/sim/shoot.sh 2 browser "wait 5"   # app index, output name, script
```

### Assets

`assets/` is generated by `tools/make_assets.py` (icons and fonts, needs
Pillow and fontTools) and `tools/make_cacert.py` (root certificates).
